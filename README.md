# Romantic Birthday Website ❤️

A cinematic, responsive birthday microsite built with plain HTML/CSS/JavaScript.

## Personalize it

Open `index.html` and replace:
- `[NAME]` with the birthday person's name
- `[YOUR NAME]` with your name

Open `script.js` and edit the `photos` array to replace the placeholder image URLs and captions.

## Music

The page uses an official YouTube embed for:
"Something About You" — Eyedress

Playback is initiated only after the user clicks the surprise button, avoiding an automatic audio download/hosting workflow.

## Run

You can open `index.html` directly in a browser, or use VS Code + Live Server for the best local development experience.
